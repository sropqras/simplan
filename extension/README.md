# simplan for Azure DevOps

Live board, project chat and AI ticket creation (Azure AI Foundry) for Azure DevOps projects.

- **simplan Board** (Boards): your work items as a live board — drag cards between states, swimlanes by
  person, filters, quick add, presence, and a lane of AI-proposed tickets to approve.
- **simplan Chat** (Boards): a chat room per project. Mention **@ai** to ask the assistant, which can read
  the parts of your repo you allow. Select messages and **Turn into tickets** to get draft work items.
- **Work item form**: linked branches and pull requests, the chat a ticket came from, one-click branch
  creation and an AI summary.
- **Ask simplan AI** in the work item menu.
- **Project settings → simplan**: configure everything here or in `.simplan.yml` in your repo.

Tickets are real Azure DevOps work items and every action runs with your own permissions.
Private extension: install is by invitation from the publisher.
